# Вэб дэлгүүрийн статик файлууд

- `site.css`, `site.js` — дэлгүүрийн загвар, хөдөлгөөн (NomadData брэнд бүк v1.0.1).
- `icons/` — 3D дүрс тэмдэг: [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji)
  (commit `1ffb34c`), 256px PNG-ээс WebP болгосон. MIT лиценз — `icons/LICENSE`.
- `flags/` — дугуй туг: [HatScripts/circle-flags](https://github.com/HatScripts/circle-flags)
  (commit `379588b`). MIT лиценз — `flags/LICENSE`. Каталогт шинэ улс нэмбэл тугийг нь
  `flags/<улсын код>.svg` нэрээр нэмнэ; байхгүй бол emoji туг харагдана.
