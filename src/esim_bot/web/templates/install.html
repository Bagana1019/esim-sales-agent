Суулгахаасаа өмнө

  • {{ svg("check") }}Утас eSIM дэмждэг эсэхийг шалга: *#06# залгахад EID гарч ирвэл дэмждэг.
  • {{ svg("check") }}Wi-Fi эсвэл үндсэн датадаа холбогдсон байна — суулгахад интернэт хэрэгтэй.
  • {{ svg("check") }}QR кодыг өөр дэлгэц (компьютер, өөр утас) дээр нээ эсвэл хэвлэ — суулгаж буй утсаараа өөрийнхөө дэлгэцийг уншуулах боломжгүй.
  • {{ svg("check") }}Өөр дэлгэц байхгүй бол QR-ын оронд и-мэйл дэх SM-DP+ хаяг, идэвхжүүлэх кодыг гараар оруулна.

iPhone

  1. Settings → Cellular (эсвэл Mobile Data) → Add eSIM-ийг дарна.
  2. Use QR Code-ийг сонгоод QR кодоо уншуулна. Гараар оруулах бол Enter Details Manually → SM-DP+ хаяг, идэвхжүүлэх код.
  3. Шинэ eSIM-д нэр өгнө, жишээ нь “Аялал”.
  4. Дуудлагад үндсэн дугаараа үлдээж, Cellular Data-г шинэ eSIM болгоно.
  5. Очсон газраа: Settings → Cellular → шинэ eSIM → Data Roaming-ийг асаана.

Samsung Galaxy

  1. Settings → Connections → SIM manager → Add eSIM-ийг дарна.
  2. Scan QR code from service provider-ийг сонгоод QR кодоо уншуулна. Гараар оруулах бол Enter activation code.
  3. Confirm дарж eSIM-ийг нэмнэ.
  4. SIM manager → Mobile data-г шинэ eSIM болгоно.
  5. Очсон газраа: Settings → Connections → Mobile networks → Data roaming-ийг асаана.

Google Pixel, бусад Android

  1. Settings → Network & internet → SIMs → Add SIM (эсвэл “+”)-ийг дарна.
  2. Download a SIM instead? → Next → QR кодоо уншуулна.
  3. Activate дарж eSIM-ийг идэвхжүүлнэ.
  4. Mobile data-г шинэ eSIM болгоно.
  5. Очсон газраа тухайн eSIM-ийн Roaming-ийг асаана.
